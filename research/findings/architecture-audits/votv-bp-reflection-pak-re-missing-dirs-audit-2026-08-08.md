# Audit: bp_reflection/ and pak_re/ missing directories

**Date:** 2026-08-08  
**Type:** Documentation bookkeeping (no code change)  
**Scope:** Every findings file that cites artifacts from `research/bp_reflection/` or `research/pak_re/` — directories that do not exist in the tree.

## Background

The `research/bp_reflection/` directory was used for kismet-analyzer JSON dumps of VOTV Blueprint bytecode (generated by `tools/bp_reflect.py`, `_fn.py`, `_cfg.py`, `_scan.py`, `_dumpstmt.py`). The `research/pak_re/` directory held extracted game assets (`.uasset`/`.uexp` from cooked PAK files) and the kismet-analyzer tool itself.

Neither directory exists in the current tree. They were likely excluded from version control (gitignored or excluded at init) because they contain game-derived artifacts. This means **every finding that cites a specific JSON dump or extracted asset from these directories cannot be independently verified** — the cited artifact is unavailable.

## Impact

The findings themselves are still valuable (the analysis and conclusions are inline), but any claim that says "see `research/bp_reflection/X.json`" or "verified via `research/pak_re/extracted/...`" references an artifact that cannot be re-read or re-verified without regenerating the dumps from the game's PAK files.

## What's still verifiable

The findings' **conclusions and analysis** are inline in the markdown — the missing directories only affect the ability to re-read the raw bytecode/asset dumps. The code-level implementations in `src/votv-coop/` are the authoritative source for what the mod actually does; the `bp_reflection/` dumps were RE aids, not source of truth.

## Regeneration

If verification is needed, the dumps can be regenerated by:
1. Extracting game PAK files into `research/pak_re/extracted/`
2. Running `kismet-analyzer to-json` on relevant `.uasset` files
3. Outputting to `research/bp_reflection/<name>.json`

The tools (`_fn.py`, `_cfg.py`, `_scan.py`, `_dumpstmt.py`) would also need to be present in `research/bp_reflection/`.
